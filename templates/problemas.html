Distribución Normal

10 problemas resueltos paso a paso · con gráfica

Fórmula base de estandarización
$$z = \frac{x - \mu}{\sigma}$$
1
Temperatura en junio
Matemáticas Online — Ejercicios de Distribución Normal, Bachillerato CCNN
En una ciudad, la temperatura máxima en junio sigue una distribución normal con media $\mu = 23°C$ y desviación típica $\sigma = 5°C$. ¿Cuántos días del mes se esperan con máximas entre 21°C y 27°C?
Paso 1 — Identificar datos
$$\mu = 23, \quad \sigma = 5, \quad x_1 = 21, \quad x_2 = 27$$
Paso 2 — Estandarizar
$$z_1 = \frac{21 - 23}{5} = \frac{-2}{5} = -0.40 \qquad z_2 = \frac{27 - 23}{5} = \frac{4}{5} = 0.80$$
Paso 3 — Tabla Z
$$P(Z < 0.80) = 0.7881 \qquad P(Z < -0.40) = 1 - P(Z < 0.40) = 1 - 0.6554 = 0.3446$$
Paso 4 — Probabilidad del intervalo
$$P(21 < X < 27) = 0.7881 - 0.3446 = 0.4435$$
Paso 5 — Días esperados (junio = 30 días)
$$30 \times 0.4435 \approx 13 \text{ días}$$
✦ Se esperan aproximadamente 13 días con temperaturas entre 21°C y 27°C.
Área sombreada: $P(21 < X < 27)$
2
Pesos de estudiantes
Distribución Normal — Ejemplos y Ejercicios Resueltos, IES Oja (matematicasiesoja.wordpress.com)
Los pesos de 500 estudiantes siguen una distribución normal con media $\mu = 70$ kg y $\sigma = 3$ kg. ¿Cuántos pesan entre 65 y 74 kg?
Paso 1 — Identificar datos
$$\mu = 70, \quad \sigma = 3, \quad x_1 = 65, \quad x_2 = 74, \quad N = 500$$
Paso 2 — Estandarizar
$$z_1 = \frac{65 - 70}{3} = \frac{-5}{3} = -1.67 \qquad z_2 = \frac{74 - 70}{3} = \frac{4}{3} = 1.33$$
Paso 3 — Tabla Z
$$P(Z < 1.33) = 0.9082 \qquad P(Z < -1.67) = 1 - 0.9525 = 0.0475$$
Paso 4 — Probabilidad del intervalo
$$P(65 < X < 74) = 0.9082 - 0.0475 = 0.8607$$
Paso 5 — Número de estudiantes
$$500 \times 0.8607 \approx 430 \text{ estudiantes}$$
✦ Aproximadamente 430 estudiantes pesan entre 65 y 74 kg.
Área sombreada: $P(65 < X < 74)$

Ensamblaje de automóviles
AnalyzeMath — Problemas de Distribución Normal con Soluciones (analyzemath.com/spanish)
El tiempo de ensamblaje de un automóvil en una planta sigue $N(20, 2)$. ¿Cuál es la probabilidad de que un auto se ensamble en menos de 19.5 horas?
Paso 1 — Datos
$$\mu = 20 \text{ horas}, \quad \sigma = 2 \text{ horas}, \quad x = 19.5$$
Paso 2 — Estandarizar
$$z = \frac{19.5 - 20}{2} = \frac{-0.5}{2} = -0.25$$
Paso 3 — Tabla Z
$$P(Z < -0.25) = 1 - P(Z < 0.25) = 1 - 0.5987 = 0.4013$$
✦ Hay un 40.13% de probabilidad de que el auto se ensamble en menos de 19.5 horas.
Área sombreada: $P(X < 19.5)$

Batería de computadora
AnalyzeMath — Problemas de Distribución Normal con Soluciones (analyzemath.com/spanish)
El tiempo entre cargas de batería sigue $N(50, 15)$. ¿Cuál es la probabilidad de que dure entre 50 y 70 horas?
Paso 1 — Datos
$$\mu = 50 \text{ horas}, \quad \sigma = 15 \text{ horas}, \quad x_1 = 50, \quad x_2 = 70$$
Paso 2 — Estandarizar
$$z_1 = \frac{50 - 50}{15} = 0.00 \qquad z_2 = \frac{70 - 50}{15} = \frac{20}{15} = 1.33$$
Paso 3 — Tabla Z
$$P(Z < 1.33) = 0.9082 \qquad P(Z < 0.00) = 0.5000$$
Paso 4 — Probabilidad
$$P(50 < X < 70) = 0.9082 - 0.5000 = 0.4082$$
✦ Hay un 40.82% de probabilidad de que la batería dure entre 50 y 70 horas.
Área sombreada: $P(50 < X < 70)$

Colesterol en hombres mayores de 50 años
Matemóvil — Distribución Normal, Ejercicios Resueltos (matemovil.com)
El nivel de colesterol sigue $N(210, 15)$ mg/dl. ¿Qué porcentaje tiene nivel superior a 250 mg/dl?
Paso 1 — Datos
$$\mu = 210, \quad \sigma = 15, \quad x = 250$$
Paso 2 — Estandarizar
$$z = \frac{250 - 210}{15} = \frac{40}{15} = 2.67$$
Paso 3 — Tabla Z · Cola derecha
$$P(X > 250) = 1 - P(Z < 2.67) = 1 - 0.9962 = 0.0038$$
✦ Solo el 0.38% de los hombres tiene colesterol mayor a 250 mg/dl.
Área sombreada: $P(X > 250)$

Salarios anuales en empresa
AnalyzeMath — Problemas de Distribución Normal con Soluciones (analyzemath.com/spanish)
Los salarios anuales siguen $N(\$50{,}000,\ \$20{,}000)$. ¿Qué porcentaje gana menos de $\$40{,}000$?
Paso 1 — Datos
$$\mu = \$50{,}000, \quad \sigma = \$20{,}000, \quad x = \$40{,}000$$
Paso 2 — Estandarizar
$$z = \frac{40{,}000 - 50{,}000}{20{,}000} = \frac{-10{,}000}{20{,}000} = -0.50$$
Paso 3 — Tabla Z

✦ El 30.85% de los empleados gana menos de $40,000 al año.
Área sombreada: $P(X < \$40{,}000)$

Talla de recién nacidos
Universidad de Antofagasta — Ejercicios Resueltos de Distribución Normal, Estadística para Bachillerato (intranetua.uantof.cl). Prof. E. Rodríguez, Ayudante R. Meza.
La talla al nacer sigue $N(50\ \text{cm},\ 2\ \text{cm})$. Si nacen 200 bebés en un mes, ¿cuántos miden entre 48 y 52 cm?
Paso 1 — Datos
$$\mu = 50, \quad \sigma = 2, \quad x_1 = 48, \quad x_2 = 52, \quad N = 200$$
Paso 2 — Estandarizar
$$z_1 = \frac{48 - 50}{2} = -1.00 \qquad z_2 = \frac{52 - 50}{2} = 1.00$$
Paso 3 — Tabla Z · Regla del 68% $(\pm 1\sigma)$
$$P(48 < X < 52) = 0.8413 - 0.1587 = 0.6826$$
Paso 4 — Número de bebés
$$200 \times 0.6826 \approx 137 \text{ bebés}$$
✦ Aproximadamente 137 bebés miden entre 48 y 52 cm.
Área sombreada: $P(48 < X < 52)$ — Regla $\pm 1\sigma$

Agua embotellada
Matemóvil — Distribución Normal, Ejercicios Resueltos Nivel 3 (matemovil.com)
Una máquina llena botellas según $N(500\ \text{ml},\ \sigma^2 = 25\ \text{ml}^2)$, por tanto $\sigma = \sqrt{25} = 5$. ¿Qué porcentaje contiene entre 495 y 508 ml?
Paso 1 — Datos
$$\mu = 500, \quad \sigma^2 = 25 \Rightarrow \sigma = 5, \quad x_1 = 495, \quad x_2 = 508$$
Paso 2 — Estandarizar
$$z_1 = \frac{495 - 500}{5} = \frac{-5}{5} = -1.00 \qquad z_2 = \frac{508 - 500}{5} = \frac{8}{5} = 1.60$$
Paso 3 — Tabla Z
$$P(Z < 1.60) = 0.9452 \qquad P(Z < -1.00) = 1 - 0.8413 = 0.1587$$
Paso 4 — Probabilidad
$$P(495 < X < 508) = 0.9452 - 0.1587 = 0.7865$$
✦ El 78.65% de las botellas contiene entre 495 y 508 ml.
Área sombreada: $P(495 < X < 508)$
10
Coeficiente Intelectual (CI)
Universidad de Valencia — Ejercicios Distribución Normal I (uv.es/ceaces)
El CI humano sigue $N(100, 15)$. En una ciudad de 1,000,000 de personas, ¿cuántas tienen $CI > 130$?
Paso 1 — Datos
$$\mu = 100, \quad \sigma = 15, \quad x = 130, \quad N = 1{,}000{,}000$$
Paso 2 — Estandarizar
$$z = \frac{130 - 100}{15} = \frac{30}{15} = 2.00$$
Paso 3 — Tabla Z · Cola derecha
$$P(X > 130) = 1 - P(Z < 2.00) = 1 - 0.9772 = 0.0228 \quad (2.28\%)$$
Paso 4 — Número de personas
$$1{,}000{,}000 \times 0.0228 = 22{,}800 \text{ personas}$$
✦ Aproximadamente 22,800 personas tienen un CI mayor a 130.
Área sombreada: $P(X > 130)$
